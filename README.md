# Clínica de estética

Landing page demonstrativa de clínica de estética, com menu responsivo, guia interativo de cuidados e formulários locais de demonstração.

> Projeto de demonstração. Nomes, profissionais, contatos, avaliações, preços, cálculos, imagens e demais dados são ilustrativos. Formulários e ações de contato funcionam apenas localmente nesta demo; não enviam dados nem solicitam atendimentos reais.

## GitHub Pages

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/(root)`, depois salve.
4. Aguarde a publicação e use o endereço exibido nessa página.

A página inicial está em `index.html` e não requer etapa de build.
